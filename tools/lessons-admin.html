📚 Doce Cuidado — Gestão de Lições & Quiz (uso interno)

Cole a URL do projeto e a service_role key do Supabase (Settings → API). Ficam salvas só no seu navegador (localStorage).
⚠️ A service_role key é secreta e dá acesso total. Use só neste computador, nunca a coloque no app nem a compartilhe. As tabelas lessons e quiz_questions são públicas para leitura; apenas esta chave permite editar.
